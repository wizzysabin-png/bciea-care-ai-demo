How it works

Designed around the patient journey.

The AI handles language and conversation while the safety layer controls escalation. A patient can remain anonymous for information, or create a consented case when follow-up is needed.

Open the AI portal →
01

Ask naturally

Type or use browser voice input in Kinyarwanda or English.

02

Understand the next step

The system identifies signals, barriers and urgency while avoiding autonomous diagnosis.

03

Create a case only with consent

A public case ID can be created for navigation without forcing a user to share more than needed.

04

Connect to a human

Referrals enter the staff dashboard where a navigator can review, update and follow up.

Built to assist people — not replace clinicians.

This demo is for education, navigation and workflow testing. It cannot diagnose breast cancer, rule it out, or replace in-person medical care. Real patient deployment requires clinician review, security hardening and privacy governance.
